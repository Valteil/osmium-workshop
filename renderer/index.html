Retroactive Merge/Void
  • Standing rules: when any of a rule's ACTIVE tags show up on a Gallery image — by any automatic means (WD14, Master Tags, Quick Merge, an accepted SynthDat image, etc.) — they're rewritten to the canonical tag, or removed entirely for a void rule (no canonical).
  • Typing an affected tag in by hand is blocked instead of silently corrected, with a toast pointing back here.
  • Retroactive: new/edited rules apply to every already-loaded Gallery image the moment you change them. Disabled and Unsaved Approved images are untouched until they're back in the Gallery (they keep whatever merge/void state they already had).
  • Full control: pause a whole rule, or toggle one of its tags off, without deleting anything — this actively unmerges/unvoids the affected images too, using the edit log to restore exactly what each one originally had.
  • Per-image exceptions: "Merge Immunize"/"Antivoid" (3-dot menu or Tag Overseer) permanently exempt one image from merge and/or void rules, regardless of what's set here.
  • Tag Pruner's own Unify/Void above creates or extends a rule here automatically — or add one by hand with "+ New rule" below.
