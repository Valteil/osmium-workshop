Connection
Enter your PC's reachable address — LAN IP (http://192.168.x.x:8188), hotspot gateway IP, or Tailscale IP/hostname (http://100.x.y.z:8188). Not 127.0.0.1 — that means "this phone" here. ComfyUI must run with --listen 0.0.0.0 --enable-cors-header --port 8188, and Windows Firewall must allow inbound TCP 8188. Note: the address loading in the phone's browser does NOT prove the app can reach it — the app needs CORS headers + cleartext allowed, the browser navigation needs neither.
