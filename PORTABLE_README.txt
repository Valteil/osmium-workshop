Dataset Tag Studio (placeholder README - real one coming later)
=================================================================

Run: Dataset Tag Studio.exe

This is a portable app - this folder is the whole thing. Nothing gets
installed anywhere else on your system.

- Your settings/themes/data live in the "data" folder next to this file.
- To update: drop the new files into "DROP_UPDATES_HERE", then inside the
  app go to Settings -> Updates & Sharing -> Apply update bundle -> Restart app.
- To move the app: copy this whole folder anywhere (another PC, a USB
  stick). To remove it: just delete the folder.
