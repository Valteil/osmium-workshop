The tools you'll actually use

All seven write to the same edit log. Nothing here silently rewrites your files behind your back.

Tag Pruner — Unify & Void

Tired of manually sorting through junk tags that mean the same thing, or tags that shouldn't be in there after using WD14? Unify and Void are persistent, dataset-wide tools that automatically filter out tags from any and all images added, stopping rogue tags from ever appearing AGAIN. Just set the rules once, and never worry about outliers from there on! Flag Isolated Tags makes this even easier!

Retroactive Merge / Void rules

Unify and Void also automatically apply to images with offending tags, even before you set them. No going back!

WD14 autotagger — no ComfyUI required

Want to tag images seamlessly but don't have ComfyUI? Don't worry. Osmium has WD14 built right in. Use your CPU to tag, or flip on Hardware Acceleration and let your GPU do it faster!

SynthDat Overseer — grow a thin dataset

Only have five good images of a character? Train a quick first-pass LoRA on what you've got, then point SynthDat at it to generate more, ControlNet-posed off one reference. That's how you grow the dataset for a stronger second pass. It pulls pose tags from the reference automatically, runs a 1- or 2-pass generation, and shows you the result before anything gets written. Accept puts it straight in the dataset. Reject parks it in Disabled instead of throwing it away.

Undo/redo, and a Log to rule them all

Made a mistake? The edit log preserves ALL edits, making sure you can edit anything from ANY point in time!

Master Tag Control — bulk passes

Checkbox-select any slice of the gallery and apply, remove, or conditionally apply tags across all of it. Rename or find-and-replace dataset-wide, or delete the selection outright. Anything you've locked or marked merge-immune just sits out, no extra clicks needed.

Sequential Edit

Need to go over your entire dataset, and refine tags at the same time? Don't waste clicks on manual inspection; Sequential Mode lets you go through EVERY image of your dataset, with easy controls per image to indicate text, censorship, perspective, and for those who are naughty, censor types.
