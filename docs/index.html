// 02 — the toolset

Six ways it keeps a dataset honest.

Every tool here writes to the same undo-able edit log, so nothing mutates your files silently.

Tag Pruner — Unify & Void

Hand-pick a set of spelling variants or junk tags, then merge them into one clean name or delete them outright. Confirmed, logged, undoable — run several independent passes for unrelated tag families.

unifyvoidmirror preview

Retroactive Merge / Void rules

Standing "these tags → this tag, or nothing" rules that auto-correct matching tags from any future source, whether it's WD14, hand typing, or imports. Typing a ruled tag by hand is blocked outright with a pointer to the rule, so cleanup never needs repeating.

standing rulesper-image immunizepausable

WD14 autotagger, on your own ComfyUI

Send one image or a whole selection to a WD14 node on your own ComfyUI instance and merge the returned tags straight in. Host, model and thresholds live in one settings panel; review-before-apply is optional. ComfyUI does the inference — Osmium ships no model of its own.

batch or singlereview modal

SynthDat Overseer — grow a thin dataset

Generate more images of a character you're training a LoRA on, ControlNet-posed from one reference. WD14-interrogate the reference for pose tags, generate a 1- or 2-pass image, then review before it's written — Accept saves straight into the dataset, Reject parks it in Disabled. Nothing is silently thrown away.

ControlNet posecrash-safe writes

Undo/redo + a full edit log

Every mutation, one tag, one merge, one mass rename, is undoable globally and individually, written to a per-folder _tag_edit_log.json. Reset a single image's edits, or audit an entire session after the fact.

global undoper-entry revert

Master Tag Control — bulk passes

Checkbox-select any slice of the gallery, then apply, remove, or conditionally-apply tags, dataset-wide rename/find-replace, or delete the selection. Locked and merge-immune images sit out of every mass op automatically.

conditional applyfind & replace
// 03 — one repo, three apps

The dataset graph follows you off desktop.

All three share the same renderer code and file conventions, so a folder tagged on desktop opens the same on mobile.

Osmium Workshop — Desktop

The full editor above. Portable Electron app for Windows: unzip, run, done.

Osmium Workshop — Mobile

Android port for tagging on the go: touch layout, on-device WD14, ComfyUI generation over LAN/Tailscale. Sideloadable APK via GitHub Releases.

Comfy Bridge

An alternate, simplified ComfyUI web UI with a built-in workflow, for when you want your image without navigating a node graph. Desktop + Android.
