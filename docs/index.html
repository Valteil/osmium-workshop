You ever see a LoRA out there that looks great, and you wanna make one yourself... but all that comes out is a mess?

Datasets are the foundation of good LoRAs, and mistagging or undertagging kills the output. Osmium Workshop is a free, feature-dense dataset manager that gets you from raw images to a clean, tagged dataset in hours instead of days. Hand-edited quality, none of the overwhelm.

Portable. Unzip and use immediately. Every edit logged and undoable. Zero telemetry.

Tagging needs nothing beyond this app. Generation (SynthDat Overseer, Comfy Bridge) is separate: both run on a bundled workflow built around Anima, a diffusion model by Circlestone Labs, and need a running ComfyUI instance. Other model families will probably load, but expect weird results outside of Anima.

The tools you'll actually use

All eight write to the same edit log. Nothing here silently rewrites your files behind your back.

Inline tag editing

Every card is its own little editor. Type into + Add tag and (with autocomplete on in Settings) you get suggestions ranked by how common they are, with the tag's definition a hover away. Click a chip for its options, double-click to rename it, hit × to drop it. Edited cards stay outlined until you save.

Tag Pruner — Unify & Void

Tired of manually sorting through junk tags that mean the same thing, or tags that shouldn't be in there after using WD14? Unify and Void are persistent, dataset-wide tools that automatically filter out tags from any and all images added, stopping rogue tags from ever appearing AGAIN. Just set the rules once, and never worry about outliers from there on! Flag Isolated Tags makes this even easier!

Retroactive Merge / Void rules

Unify and Void also automatically apply to images with offending tags, even before you set them. No going back!

WD14 autotagger — no ComfyUI required

Want to tag images seamlessly but don't have ComfyUI? Don't worry. Osmium has WD14 built right in. Use your CPU to tag, or flip on Hardware Acceleration and let your GPU do it faster!

SynthDat Overseer — grow a thin dataset (needs ComfyUI)

Only have five good images of a character? Train a quick first-pass LoRA on what you've got, then point SynthDat at it to generate more, ControlNet-posed off one reference. That's how you grow the dataset for a stronger second pass. It pulls pose tags from the reference automatically, runs a 1- or 2-pass generation, and shows you the result before anything gets written. Accept puts it straight in the dataset. Reject parks it in Disabled instead of throwing it away.

Undo/redo, and a Log to rule them all

Made a mistake? The edit log preserves ALL edits, making sure you can edit anything from ANY point in time!

Master Tag Control — bulk passes

Checkbox-select any slice of the gallery and apply, remove, or conditionally apply tags across all of it. Rename or find-and-replace dataset-wide, or delete the selection outright. Anything you've locked or marked merge-immune just sits out, no extra clicks needed.

Sequential Edit

Need to go over your entire dataset, and refine tags at the same time? Don't waste clicks on manual inspection; Sequential Mode lets you go through EVERY image of your dataset, with easy controls per image to indicate text, censorship, perspective, and for those who are naughty, censor types. Visual customizability

26 themes, common to legendary, and each one is a whole look: its own typefaces, button and tag shapes, textures, and hover effects, not just a palette swap. Night mode sits on top of whichever one you're using and keeps every label readable. Don't take the screenshots' word for it: pick one from the Theme menu up top and this page wears it.
