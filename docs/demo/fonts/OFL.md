# Bundled fonts

Every `.woff2` in this folder is a Latin subset of a font family licensed under the
**SIL Open Font License, Version 1.1** (https://openfontlicense.org), downloaded from
Fontsource (https://fontsource.org), which mirrors Google Fonts. The fonts are bundled
unmodified. The copyright for each family stays with its designers, as listed on that
family's Google Fonts page.

Families: Albert Sans, Alegreya, Alegreya Sans, Anybody, Archivo, Audiowide, Barlow,
Barlow Condensed, Barlow Semi Condensed, Big Shoulders Display, Chakra Petch, Cinzel,
Courier Prime, Eczar, Epilogue, Exo 2, Figtree, Fredoka, Gilda Display, Gloock,
IBM Plex Sans, IM Fell English SC, JetBrains Mono, Jost, Karla, Libre Caslon Text,
Marcellus SC, Michroma, Nunito, Overpass, Oxanium, Pirata One, Poiret One,
Saira Stencil One, Schibsted Grotesk, Shippori Mincho, Sora, VT323, Zen Kaku Gothic New,
Zen Maru Gothic.

The OFL allows these fonts to be used, bundled, and redistributed with software. The
fonts cannot be sold on their own.
